# SQLD 나만의 문제은행 — 개발 문서 세트

SQLD(SQL 개발자) 시험 대비용 **개인 문제은행·모의고사 웹사이트**를 VS Code + Claude Code(CLI)로 만들기 위한 문서 묶음입니다.

## 문서 구성

| 파일 | 역할 | 언제 보나 |
|---|---|---|
| `CLAUDE.md` | Claude Code가 매 세션 자동으로 읽는 **프로젝트 규칙** | 프로젝트 루트에 그대로 둠 |
| `docs/01_프로젝트계획서.md` | 무엇을, 왜, 어떤 구조로 만드는지 (전체 설계) | 시작 전 1회 정독, 설계 판단이 필요할 때 |
| `docs/02_작업지시서.md` | 단계(Phase)별로 Claude Code에 **그대로 붙여 넣을 지시문** | 매 작업 시작 시 |
| `docs/03_상세단위업무계획서.md` | 단위 작업(Task) 목록 — 산출물, 완료 기준, 진행 체크 | 작업 진행·검수할 때 |
| `docs/04_문제출제기준.md` | SQLD 출제 범위, 문제 유형, 문제 JSON 형식, 해설 작성 규칙 | 문제를 만들거나 추가할 때 |
| `docs/05_CLI_진행가이드.md` | VS Code에서 Claude Code로 실제 진행하는 방법 | 처음 시작할 때, 막힐 때 |

## 사용 순서 (요약)

1. 빈 폴더 `sqld-bank`를 만들고 이 묶음의 파일을 모두 넣는다 (`CLAUDE.md`는 루트, 나머지는 `docs/`).
2. VS Code로 폴더를 열고 터미널에서 `claude` 실행.
3. `docs/02_작업지시서.md`의 **Phase 0**부터 지시문을 하나씩 붙여 넣는다.
4. 각 Phase가 끝나면 `docs/03_상세단위업무계획서.md`의 체크박스를 확인·갱신한다.
5. 자세한 방법은 `docs/05_CLI_진행가이드.md` 참고.

## 핵심 설계 한 줄 요약

- 문제는 **JSON 파일**로 프로젝트 안에 포함 (DB 불필요)
- 풀이 기록·오답노트·직접 추가한 문제는 **브라우저 저장소(IndexedDB)** + JSON 백업/복원
- SQL 결과예측 문제는 브라우저 안의 **SQL 엔진(sql.js)**이 매번 새 데이터로 생성·채점 → AI 사용량 0
- 무료 정적 호스팅(GitHub Pages)에 올려 **PC·모바일 모두** 사용, PWA로 홈 화면 설치
- 기기 간 기록 동기화는 선택 단계(Phase 10, Supabase)로 분리
