# 02. 작업지시서

Claude Code에 **그대로 복사해 붙여 넣는** 지시문 모음이다. 한 번에 하나씩, 위에서부터 진행한다.
각 지시문 끝의 "보고 형식"은 모든 단계 공통이므로, 지시문에는 짧게만 적었다.

## 공통 보고 형식 (매 작업 완료 시 Claude Code가 지킬 것)

```
[완료 보고] Task ID
1. 한 일: (바꾼 파일과 요지)
2. 확인 방법: (어느 화면에서 무엇을 눌러 보면 되는지 / 실행할 명령)
3. 테스트: npm run build / npm test 결과
4. 남은 이슈·결정 필요 사항: (없으면 "없음")
[커밋 제안]
- 바뀐 파일: (목록)
- 커밋 메시지: (Task ID: 한 줄 요약)
```

> 커밋·푸시는 사용자가 직접 한다. 완료 보고를 확인하고 화면까지 눌러 본 뒤, 제안된 메시지로 커밋한다 (방법은 `05_CLI_진행가이드.md` §7).

## 막혔을 때 쓰는 지시문

| 상황 | 지시문 |
|---|---|
| 에러가 났을 때 | `npm run dev 하니까 이런 에러가 나: (에러 붙여넣기). 원인을 설명하고 고쳐 줘.` |
| 화면이 이상할 때 | `#/exam 화면에서 모바일 폭일 때 보기 버튼이 잘려. 원인 찾아서 고쳐 줘.` (스크린샷 경로를 함께 주면 더 정확) |
| 코드가 이해 안 될 때 | `src/engine/template.ts가 어떤 흐름으로 동작하는지 초보자 눈높이로 순서대로 설명해 줘. 코드는 고치지 마.` |
| 문서와 다르게 하고 싶을 때 | `T5-3에서 타이머를 90분이 아니라 설정에서 바꿀 수 있게 하고 싶어. docs/01, 03도 함께 수정해 줘.` |
| 진행 상황 확인 | `docs/03 기준으로 지금 어디까지 완료됐고 다음에 할 Task가 뭔지 알려 줘.` |
